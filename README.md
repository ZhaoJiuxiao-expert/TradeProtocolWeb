# 有据 · 交易协议实验场

首页为模拟交易实验区。[/direct](https://open-trade-ledger-lab.elvenscone32.chatgpt.site/direct) 是独立的商户直收订单区。两个入口分别维护交易记录。匿名身份绑定原浏览器 Cookie，清除后无法用该浏览器找回原身份。

## 普通个人卖家异地交易

打开 [/personal](https://open-trade-ledger-lab.elvenscone32.chatgpt.site/personal)。卖家先在闲鱼发布允许交易的商品，再登记该商品的闲鱼官方详情页。买家到闲鱼核对卖家和价格，在闲鱼下单、付款、收货及处理售后。本站提供商品跳转与双方交割声明；没有取得闲鱼订单查询、代收、分账或退款 API 授权。请在闲鱼官方页面处理身份证明与签约。

本站卖家核实对应款项实际到账后确认，买家收到商品后确认，先后顺序不限。双方各自从闲鱼订单详情取得同一笔订单号；第一次确认保存在后台，第二方确认且编号匹配才写一条公开交割结果。公开账本不披露闲鱼订单号，也不构成闲鱼或银行出具的资金凭证。本站不从该渠道扣款。闲鱼可能收取的费用以该平台实际订单为准。

参考：[闲鱼社区用户服务协议](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_other/suit_bu1_other201708081618_51146.html)。

## 商户直收与双确认

卖家登记商品，买家下单。卖家从自己已开通的微信支付 Native 商户系统获取与该笔订单金额对应的有效 code_url，将订单专属收款请求交给买家。网页在浏览器内生成二维码。买家使用另一台设备的微信扫一扫，并在微信收银台核对商户名和金额。支付由商户和微信支付直接处理。

卖家核对自己的商户账单并完成交付后确认；买家实际付款并收到约定商品或服务后确认。网站只在两个不同交易身份都确认后标记订单完成。该记录属于当事方的声明，不是支付机构回执或法定所有权登记。平台未开通资金托管、实名校验、支付回调、代退款或真实手续费分账。若遇金额不符、超时或订单状态未知，应先让商户查原单再处理，避免重复付款。订单码只对交易双方可见，不进入公开账本；请勿在商品描述或公开字段粘贴付款码、电话或收件信息。

参考：[微信支付 Native 开发指引](https://pay.wechatpay.cn/doc/v3/merchant/4012791891)。

## 模拟交易体验



打开首页可购买演示卖家的二手相机、游戏商品或分阶段服务。演示卖家自动交付，买家逐阶段验收；每笔订单对卖方已取得的总额累计计收 2% 模拟平台费。访客也可发布商品，用另一浏览器身份购买，再由原卖家交付。争议自动冻结剩余托管资金，对手方可以接受平分方案，之前已结算的阶段保持有效。单机演示商品由模拟卖方自动应答。普通订单若双方不达成一致，保持冻结。

交易记录可从 /api/ledger 导出。每个区块包含上一区块的 SHA-256 摘要。该实验链由网站服务器维护，验证说明随账本提供；用户可留存历史快照以对比后续版本。商品发布、成交与参考价更新使用同一个数据库事务。比较同条件已完成订单时同时计算最近 21 笔订单中位数和商家等权中位数；达到 3 个不同卖家才公布。演示身份可免费创建，价格指数用于功能测试。

## 本地运行

需要 Node.js 24 或以上。在仓库根目录运行：

    node build.mjs
    node server.mjs

访问 http://127.0.0.1:4391 。本地服务使用 SQLite，将运行数据保存在 .local/。托管服务使用同一份 Worker 和 D1 持久化账本。public/index.html 为前端，worker.js 实现交易规则，schema.sql 为数据库结构，drizzle/ 为部署迁移。可使用两个浏览器配置测试不同买卖双方。

research/ 收录早期定价压力模拟；以 Python 3 执行 python research/simulate.py 一个尚不存在的目录，即可重新生成五个场景的账本。实验数据与公共网站的交易分开保存。
